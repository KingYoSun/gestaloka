# プレイコマンドと世界変更の契約

Web・CLI・botのプレイ操作は `/api/worlds/:id/session` の `PlayerPlayCommand` で受け付ける。サーバー担当NPCも同じコマンド型を使う。以下のSPは一申請あたりの上限で、消費する時点と再送時の扱いは [ADR-094](adr/ADR-094-play-command-sp-quotes.md) に従う。`0` SPの操作にも、手番・権限の確認やGM審査が必要なものがある。

`apply` への切り替えで、生成は新規抽選した案ごと、対抗は新規抽選ごと、正式改名は採否を保存した審査ごとに1 SPを使うようになった。[採用した料金](adr/ADR-091-typed-world-application.md#決定)

世界の差分を確定するときは、操作ごとに許可した追加・改訂・関係の終了を照合する。受領が必要な操作は、承認か期限に応じて確定する。追従・観測・ファンブルなどの副次作用は、元の申請の直接対象と区別して扱う。[確定時の検査](adr/ADR-091-typed-world-application.md#各入口で共用する確定時の検査)

`PlayCommand` の `update`・`create`・`create-batch`・`oppose`・`rename` はサーバー内部の計画用の形式で、公開のプレイ入口は `apply` を受け付ける。旧 `/actions`・`/play/resume`・`POST /scene` は旧形式の書き込みを終了し、通常のプレイ入口を案内する。保存済み受領と確定記録は [ADR-091](adr/ADR-091-typed-world-application.md) の規定で扱う。
