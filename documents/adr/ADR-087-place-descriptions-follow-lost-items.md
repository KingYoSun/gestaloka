# ADR-087 場所の物が判定で外れたら、GMがその場所の説明を物の無い説明に置き換える

状態: 採用。2026年11月24日のユーザー判断を記録する。Issue #445 の対応。

## 問題

場所の説明（場所の status/content）が「炉と金床がある」のように物の存在を述べていても、その物が壊されたり喰われたりして場所の持ち物から外れたとき、説明は書き換わらなかった。「金床がある」と「金床は失われた」が同じ場所に同時に有効になり、場所を訪れた人には両方が提示された。この食い違いは、行動の種類や世界の設定によらず起きる。

場所の物が外れる判定には、二つの経路がある。製作の材料として場所に置かれた物を使い切る経路（作成・更新の判定の `requiredMaterials`）と、対抗行動の操作で場所の物を取り除く・持ち去る経路である。

## 決定

- **物が外れうる場所の説明を、GMへ relationId 付きで渡す。** 製作の判定では本人の現在の滞在先を、対抗行動では操作で物を外される持ち主（人物以外）を材料に加え、その状態に relationId を付ける。
- **GMは、置き換える説明を返す。** 判定の応答に `placeStates:[{relationId, text}]` を返してよい。物の存在を述べる説明の relationId と、外れた物を除いた新しい説明である。該当がなければ省く。
- **成功した確定で、実際に物が外れた場所の説明だけを置き換える。** 確定の変更で物を持つ関係が終わった持ち主の、現在の status/content だけを終える。人物の状態は対象にしない。新しい説明は、判定で付いた状態（ADR-084 の印 `judged`）として同じ確定に加える。
- 物の名前と説明の文字列は照合しない。どの説明が物の存在を述べているかはGMが判断する。
- 場所の説明から物を作る申請が、すでに持ち出された物をもう一度作れてしまう点は、今回は扱わない（ユーザー判断）。説明から持ち出された物が外れるようになるので、起きにくくなる。

## 受入条件と判定

特定の行動や結末は期待値にしない。

| 対象       | 期待結果                                                                                      | 判定方法       |
| ---------- | --------------------------------------------------------------------------------------------- | -------------- |
| 製作の判定 | 場所の物を材料に使い切る判定の指示に `placeStates` が入り、場所の説明が relationId 付きで渡る | 結合試験       |
| 対抗行動   | 場所の物を取り除く対抗行動の指示に `placeStates` が入り、場所の説明が relationId 付きで渡る   | 結合試験       |
| 置き換え   | 成功すると、GMが選んだ説明が終わり、新しい説明が場所に残る                                    | 結合試験       |
| 文書       | ダイスの解説と変更履歴に、場所の説明の置き換えを書く                                          | 配布文書の照合 |

## 影響

- 製作の判定と対抗行動の判定の入力に、場所の状態の relationId と指示が加わる。出力に `placeStates` が加わることがある。応答の `outcome.setting.placeStates` で読める。
- 物が外れた場所の説明が、成功時に書き換わる。終わった説明は履歴に残る。
- プレイヤーCLIの解説が変わるため、CLIの版を 1.21.7 に上げる。
