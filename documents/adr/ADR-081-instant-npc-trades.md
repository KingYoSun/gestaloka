# ADR-081: 出現個体との取引

状態: 採用。2026年11月23日のユーザー判断を記録する。[ADR-053](ADR-053-search-appearances.md)の発生用ノードと、[ADR-069](ADR-069-deferred-receipts-and-exchanges.md)の公開交換を、出現個体に広げる。

## 問題

検索で出現する個体は、セッションの同席者としてだけ存在し、共有グラフのノードを持たない（[ADR-056](ADR-056-instant-npc-turns.md)）。持ち物は存在から存在への `has` で表すので、個体は物を持てず、受け取ることも渡すこともできない。

このため、売り手や配達人のように、物の受け渡しが前提になる役割を発生用ノードで定義しても、その役割が成立しなかった。個体は売り物を口にするだけで、買おうとする申請は相手を指定できずに終わる。

## 決定

- **取引は発生用ノードで設定する。** 品物の発生用script（`spawn.kind` は `existence`）から、個体を出現させた発生用ノードへ `status/about` の `text` を `spawn-trade` として結ぶ。ドロップの `spawn-death`（[ADR-064](ADR-064-instant-npc-death-and-drops.md)）と同じ方式である。品物の `spawn` には代価 `price`（系列 `seriesId`、呼称 `label`、個数 `count`）を指定する。`price` のない設定は読まない。
- **1回の受領で渡す個数は発生数とする。** `maxCount`（旧形式では `count`）を使う。`probability` と `minCount` は使わない。品物の呼称は、検索で現れる物品と同じく `species：description` とする。
- **個体が同席している間だけ、公開交換と同じ形で示す。** 同じ場所にいる人物の `exchangeOffers`（周囲検索と画面）に並ぶ。交換IDは個体のIDと品物の発生用ノードのIDから決まる。品物の発生用ノードのIDは、他の発生用ノードと同じくプレイヤーへ返さない。個体が去ると取引もなくなる。
- **受領には既存の `exchange` を使う。** 代価の系列と個数を満たす手持ちの品を指定する。成立すると、品物が買い手の手元に新しく生まれ、代価は世界から除かれる。両方を一つのグラフ確定に含める。個体はノードを持たないので、在庫と代価の受け取り先は持たない。
- **個体は自分の取引を知っている。** 個体の手番でモデルに渡す入力に、品物・個数・代価・掲示文を加える。成立した交換は、他の行動と同じくセッションの記録として個体にも届く。

## 影響

- 代価は消え、品物は生まれる。世界の通貨と物品の総量は、取引のたびに変わる。量の調整は、世界の作者が代価と発生数で行う。
- 受領で生まれた品物は、受領のたびに別の物品になる。手持ちの同じ品へはまとめない。
- 手動で登場させた個体と、`ruleId` のない旧記録の個体は、取引を持たない。
- 契約には `spawn.price` が増える。既存の発生用ノードはそのまま読める。プレイヤーCLIの説明を更新し、1.16.0とする。

## 受入条件と判定

| 対象         | 期待結果                                                                                   | 判定方法       |
| ------------ | ------------------------------------------------------------------------------------------ | -------------- |
| 表示         | 個体が現れた検索の応答に取引が並び、品物の発生用ノードのIDは含まれない                     | 結合試験       |
| 受領         | 系列と個数を満たす代価で、代価が減り、品物が買い手の手元に生まれる。再送で二重に適用しない | 結合試験       |
| 代価の不一致 | 呼称が同じでも系列のない品は拒否し、何も変えない                                           | 結合試験       |
| 個体の手番   | モデルへの入力に、品物・個数・代価・掲示文が入る                                           | 結合試験       |
| 退去後       | 個体が去った後は、同じ交換IDで受領できない                                                 | 結合試験       |
| 文書         | 世界生成のプロンプトと配布文書に、設定方法と買い方がある                                   | 配布文書の照合 |
