# ADR-088 判定で損傷の付いた乗り物は、動く前にGMが動けるかを判断する

状態: 採用。2026年11月24日のユーザー判断を記録する。Issue #444 の対応。[ADR-077](ADR-077-vehicles.md)の運行の確認に加える。

## 問題

乗り物に「車体が潰れて走れない」といった状態が付いていても、乗車・運行・同行の移動は通常どおり受理された。運行の確認が照合するのは、乗り物・操縦権・能力・経路の構造の状態だけで、乗り物の現在の状態（自由記述の status）は読まないためである。状態の記録と移動の扱いが食い違い、壊れたはずの乗り物が走り続けた。この食い違いは、行動の種類や世界の設定によらず起きる。

自由記述の状態の文字列で移動を止めることはしない（世界や言い回しに依存するため）。

## 決定

- **判定で付いた状態がある乗り物だけ、移動の前にGMが判断する。** 乗り物に、判定で付いた現在の状態（ADR-084 の印 `judged`）があれば、GMにその状態を渡し、人や荷を乗せて移動できるか（`movable`）と理由（`reason`）を返させる。判定で付いた状態が無い乗り物の移動では、GMは呼ばない。
- **動けなければ移動を断る。** 運行、乗り物自身の自走、同行の移動の申請、設置した乗り物の移設では、動けないと判断されれば `VEHICLE_DISABLED` で断る。理由をメッセージに入れる。通常枠もSPも使わない。
- **追従では、動けない乗り物はその場に残る。** 同行者の移動に付いてくる乗り物が動けないと判断されたときは、追従させず、同行者の移動は確定する。
- 損傷の状態が終われば（期限が来る、修理して終える）、判断なしで動ける。
- 判断の呼び出しは要求IDと乗り物から導いたIDで識別し、同じ入力の再送は同じ呼び出しにする。

## 受入条件と判定

特定の行動や結末は期待値にしない。

| 対象     | 期待結果                                                                               | 判定方法       |
| -------- | -------------------------------------------------------------------------------------- | -------------- |
| 損傷なし | 判定で付いた状態の無い乗り物の移動では、GMを呼ばない                                   | 結合試験       |
| 動けない | 判定で付いた損傷があり、GMが動けないと判断すると、自走は `VEHICLE_DISABLED` で断られる | 結合試験       |
| 追従     | 同行の乗り物は、動けると判断されれば追従し、動けないと判断されればその場に残る         | 結合試験       |
| 文書     | 乗り物の解説と変更履歴に、損傷のある乗り物の判断と `VEHICLE_DISABLED` を書く           | 配布文書の照合 |

## 影響

- 判定で損傷の付いた乗り物の移動ごとに、GMの呼び出しが一回増える。損傷の無い乗り物の移動は変わらない。
- 新しいエラー `VEHICLE_DISABLED` が加わる。
- プレイヤーCLIの解説が変わるため、CLIの版を 1.21.8 に上げる。
