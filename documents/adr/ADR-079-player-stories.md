# ADR-079 STORIES

[Issue #375 の実装方針](https://github.com/KingYoSun/gestaloka/issues/375#issuecomment-7085994151)

プレイヤーが自分の視点で書いた記録を STORIES として公開する。一行の読み切りも、繰り返し続きを書く連載も、作品と話の組み合わせで扱う。第一話の公開時に作品を作り、続きを追加するたびに作品内で次の話数を割り当てる。

Web と CLI から投稿できる。新しい作品を公開するときは、書き手が参加した世界、作品名、作品に表示する著者名、本文を指定する。CLI では参加済みの人物を認可された接続先の世界に投稿する。続話を投稿できるのは、作品を公開したアカウントに限る。連載の話数の割り当てと保存は一つのトランザクションで行い、同じ投稿の再送には保存済みの結果を返す。

作品と各話は PostgreSQL に保存する。世界のIDと投稿時の世界名を作品に添える。投稿・閲覧の処理は STORIES のデータを対象とし、共有グラフ、シーン履歴、登場人物の観測や記憶から独立させる。

各話の公開時に静止画を一枚添えられる。人物アイコンと同じ入力形式、ファイル容量、画像寸法の範囲を使う。縦横比を保って長辺1,600 px以内の WebP に変換し、本文と同じトランザクションで保存する。画像本体は各話を読むときに指定して取得する。

公開後、著者本人は Web または CLI から作品名・著者名と、各話のタイトル・本文・添付画像を修正できる。作品名と著者名は全話に反映する。各話のタイトルは任意で、本文の見出しと目次に表示する。各話では画像の追加・差し替え・削除ができ、Web では画像を本文の前に表示する。

作品全体と個別の話を削除できる。削除した作品・話は公開対象から外し、残った話は元の話数で読める。最後の話を削除すると作品も一覧から外れる。投稿・修正・削除の要求ごとに内容の照合値と受付結果を保存し、再送には当初の結果を返す。ブックマークは作品単位で、閲覧者本人のアカウントに保存する。Web と CLI から本人のブックマーク一覧を読める。

作品を読めるのは、投稿先の世界にプレイヤーを持つアカウントに限る。Web と CLI は同じ API で閲覧権限を確認する。CLI の接続先や進行中のセッションにかかわらず、作品一覧とブックマーク一覧にはそのアカウントが読める作品だけを表示する。作品一覧は世界・プレイヤー・著者名・作品名・第一話の公開日で絞り込める。プレイヤーによる絞り込みには、著者名が違っても共通する公開用の識別子を使う。連載の目次は各話の公開日で絞り込める。日付は日本時間とし、端の日を含めて絞り込む。一覧と目次は選んだ並び順でページに分け、本文は指定した一話分を取得する。
