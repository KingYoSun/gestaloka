# ADR-036: 履歴の共有参照と同一照会の再利用

状態: 候補実装。実モデルでの費用と物語体験の比較は未完了。

## 対象と完了条件

2026年11月9日のユーザー依頼により、物語体験を保ちながら履歴の再投入と重複取得を減らす。今回の範囲は、履歴を削らずに同じ情報の取得・送信をまとめる処理とする。

1. OpenAI Responsesへ送る重複したノード・関係・長文を共有参照へ置き換える。本文、同一性、期間、来歴、変更フラグを含む入力データを復元し、保存要求との一致を確認する。対象は費用調査に使った40シーンを含む保存済み647要求とする。
2. 同一のWorldContext内で、対象・関係・向き・期間・ページが同じ履歴を再取得しない。観測と履歴照会の実DB読取を比較し、期間の異なる照会と、版が変わった後の読取・確定も検証する。
3. 保存済み要求の送信量を削減する。設定版、モデル配分、出力上限、世界予算と呼出し上限は維持する。旧方式の保存済み応答を追加送信なしで再利用できることを確認する。
4. 同じ開始状態・人物条件・入力を用い、履歴の多い村の場面と、認知条件の異なる人物がいる観測所の場面を比較する。シーン全提示の意味的新規性と重要度を、原文の引用付きで評価する。費用は修正・追加照会も含めて通算し、特定の行動や結末、応答の再現性を採否条件にしない。

実モデル比較が未完了の間は、文字数の削減や構造検証を物語体験の維持・費用削減の実証として扱わない。

## 実装

既存の共有参照形式を、Anthropicに加えてOpenAI Responsesの背景準備と世界更新でも使う。期間や記述が異なる同じIDの記録を統合せず、記録ごとの違いを残す。行動解決・意図形成・リザルトには今回の参照化を適用せず、既存の送信形式を保つ。GeminiとChat Completionsの送信方式は今回の変更対象に含めない。

WorldContextの履歴読取結果を、同じ照会の間だけ再利用する。関係集合の版の取得と検証は毎回行い、古い結果で競合を隠さない。異なる期間・方向・ページは別の読取とし、進行中シーンの差分との統合は既存処理を使う。

履歴の件数による打ち切り、要約への置換、意味に基づく履歴の選別、改善専用のLLM呼出しは追加しない。保存データと公開API・CLIの契約は変更しない。

## 検証時の制約

開発検証には本番の世界予算とは別の通算20ドル枠を設け、その後のユーザー承認により上限を30ドルへ変更した。初期の検証用通信に日本語の分割受信の不備が見つかったため、その通信を通した試行を採否資料から除外し、要求・応答・費用を残す。修正後は送信本文のハッシュを照合する。既存の世界・人物・履歴を検証のために変更しない。
