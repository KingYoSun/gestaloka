# ADR-036: 履歴の共有参照と同一照会の再利用

状態: 採用。2026年11月9日。

## 対象と完了条件

2026年11月9日のユーザー依頼により、物語体験を保ちながら履歴の再投入と重複取得を減らす。今回の範囲は、履歴を削らずに同じ情報の取得・送信をまとめる処理とする。

1. OpenAI Responsesへ送る重複したノード・関係・長文を共有参照へ置き換える。本文、同一性、期間、来歴、変更フラグを含む入力データを復元し、保存要求との一致を確認する。対象は費用調査に使った40シーンを含む保存済み647要求とする。
2. 同一のWorldContext内で、対象・関係・向き・期間・ページが同じ履歴を再取得しない。観測と履歴照会の実DB読取を比較し、期間の異なる照会と、版が変わった後の読取・確定も検証する。
3. 保存済み要求の送信量を削減する。設定版、モデル配分、出力上限、世界予算と呼出し上限は維持する。旧方式の保存済み応答を追加送信なしで再利用できることを確認する。
4. 同じ開始状態・人物条件・入力を用い、履歴の多い村の場面と、認知条件の異なる人物がいる観測所の場面を比較する。シーン全提示の意味的新規性と重要度を、原文の引用付きで評価する。費用は修正・追加照会も含めて通算し、特定の行動や結末、応答の再現性を採否条件にしない。

文字数の削減や構造検証だけを、物語体験の維持・費用削減の実証として扱わない。

## 実装

既存の共有参照形式を、Anthropicに加えてOpenAI Responsesの背景準備と世界更新でも使う。期間や記述が異なる同じIDの記録を統合せず、記録ごとの違いを残す。行動解決・意図形成・リザルトには今回の参照化を適用せず、既存の送信形式を保つ。GeminiとChat Completionsの送信方式は今回の変更対象に含めない。

WorldContextの履歴読取結果を、同じ照会の間だけ再利用する。関係集合の版の取得と検証は毎回行い、古い結果で競合を隠さない。異なる期間・方向・ページは別の読取とし、進行中シーンの差分との統合は既存処理を使う。

履歴の件数による打ち切り、要約への置換、意味に基づく履歴の選別、改善専用のLLM呼出しは追加しない。保存データと公開API・CLIの契約は変更しない。

## 検証時の制約

開発検証には本番の世界予算とは別の通算20ドル枠を設け、その後のユーザー承認により上限を30ドルへ変更した。初期の検証用通信に日本語の分割受信の不備が見つかったため、その通信を通した試行を採否資料から除外し、要求・応答・費用を残す。修正後は送信本文のハッシュを照合する。既存の世界・人物・履歴を検証のために変更しない。

## 確認結果

保存済み647要求の877入力データを共有参照から復元し、本文・期間・来歴・変更フラグを含む元データとの一致を確認した。送信文字数は225,589,796文字から175,868,246文字へ22.0%減った。同一の420件の観測・履歴を読む照会では、取得結果と依存版を保ったまま履歴データの実DB読取が2回から1回になった。版の変化、異なる期間、旧保存要求の無送信再利用もテストした。

| 比較条件                         | 基準の計算額 | 最終候補の計算額 | 削減率 |
| -------------------------------- | -----------: | ---------------: | -----: |
| 長い履歴を持つ帰宅・回想の場面   |  $6.08080245 |      $4.00810605 |  34.1% |
| 非音声で伝える装置を観察する場面 |  $0.16909770 |      $0.15844300 |   6.3% |
| 合計                             |  $6.24990015 |      $4.16654905 |  33.3% |

長履歴条件は、正常な保存済みプレイを基準とした。開始前の41確定記録を隔離世界へ復元し、当時の取得結果との一致を確認してから、元と同じ人物条件・目的・3入力を候補で実行した。別設定では同じ開始状態・2入力で基準と候補を実行した。最終候補は両条件とも追加のシーン分割なしでリザルトまで完了した。

意味検品はnarrative-inspection-v13 / meaning-v6を使い、保存済みの全提示をAIが手動で評価した。長履歴条件の新情報は双方5単位・重要度2以上は双方0単位で、既知の回想を新情報へ再計上していない。別設定は双方7単位・重要度2以上は双方2単位だった。可視範囲と固定具の確認限界、意味が未確定な装置の反応が、次の選択に与える意味を確認した。実際の表現・提示順の違いと正確な引用は、非公開の検証記録へ保存した。NPCの特定行動や完全回答、応答の再現性、世界状態・指示への正確な追従を採否条件にはしていない。

自由登録人物のpreset未指定メタデータを既存の自動manifest契約が受理できず、比較資料の取得では保存済みの提示・宣言・既知資料を使った。この取得上の問題と本文の問題は区別し、公開検品契約は変更していない。

初期の通信不備を含む開発検証の計算額は24.68996770ドル、未精算予約は0だった。通信不備を通した2試行は16.00633385ドルで、費用を含めて保持した。途中候補では早いシーン終了があったため、圧縮が不要な行動解決段階まで変わっていた入力形式を従来方式へ戻し、同じ2条件で最終候補を確認した。

各条件一試行の比較であり、一般的な満足度や全設定での無劣化を実測したものではない。費用差には照会回数・生成内容・実行時点のキャッシュの違いも含み、工程単独の因果効果と同一視しない。履歴そのものは保持しており、蓄積に伴う費用増加が止まることは示していない。
