# ADR-095 状態によるコマンド制限と原因の表示

2026年11月25日に #439 の対応を決めた。

状態の確定時に、その状態が有効な間は常にできない操作を `status/content` の関係に保存する。発声、本人の移動、乗り物の運行を対象とする。制限の有効期間は状態と同じとし、修理、治療、期限到達で状態が終了すると制限も解ける。状態の本文は自由記述で残す。

`say` は発声と、筆談や身振りなどの無声の行動を区別する。従来の `say` は発声として受け付ける。発声を制限している間も無声の行動を選べる。故障中の乗り物には乗車でき、運行できない理由を確認できる。

エラーには、申請者が読める原因の状態を、関係の短縮IDと本文付きで返す。CLIで表示する短縮IDはそのまま状態の関係IDとして指定できる。無声の行動は、その場で観測した行動として保存する。

記録済みのコマンド制限は、操作の受付と確定で照合する。乗り物の旧状態と場所の文脈に依存する作用は、既存の可否判定で扱う。同じ条件と参照した版なら判断を再利用する。旧状態に制限を付ける場合は、対象を確認して管理修正する。

死亡の確定と既存のペナルティは `fatal` を起点に処理する。目撃と結果の提示には確定済みの出来事を使う。
