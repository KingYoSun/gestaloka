# ADR-002: 共通の世界更新と主体ごとの知識

状態: 採用。2026-10-19。

## 今回の完了範囲

Issue #27・#28のうち、文脈照会、自由記述行動、候補修正、依存の再検証、確定と再開を共通のWorldAgentへ接続する。構造・接続・履歴・情報の分離は実DBテスト、意味的な帰結は実モデルの保存記録で確認する。時間指定の試遊管理、キュー配分、公開API・画面は次の実装範囲とする。

## 実行と確定

世界更新Agentには基本契約を常時渡し、必要な調査手順をprompts/skillsから照会できる。世界情報は共有グラフから取得し、スキルや管理者向けの説明へ複製しない。照会は空結果を含む依存版を記録する。effectは参照先から上流へ探索し、循環を訪問済み集合で止める。区間の途中だけで有効な作用も取得する。

PostgreSQLには要求、開始時のプロンプト、呼出し結果への参照、未確定候補、依存版、実行世代を保存する。LangGraphのtaskと予算台帳を通じ、保存済みの応答を再利用する。実行の引継ぎは短い受付ロックとNeo4jの世代更新を関連づけ、進捗保存と結果公開はclaim_keyが一致する場合に限る。LLM待機中はロックを保持しない。

競合時は未確定候補を破棄して文脈を取り直す。確定済みreceiptがあれば結果保存を復旧し、帰結を再生成しない。保留は世界内の失敗とは別に保存する。明示再開でも応答不明の同じ呼出しを自動再送せず、未精算予約を保持する。

## 主体ごとの知識

意図形成には、その存在に成立したseeの観測本文とinterpretの内容だけを渡す。管理者入力、対象ノードの全内容、未観測の状態、世界更新Agentの要約は渡さない。seeの有効期間が終了しても、過去に得た観測を閲覧できる。閲覧や内部照会ではseeを追加しない。

seeには観測した側面、処理済み世界内時点、情報源、作用経路を保持できる。情報源・経路の版はサーバーが確定時に付与し、モデル指定の版を採用しない。時間経過と情報源の変化を別々に返し、どちらも新たな知覚や現実変化の証明とはしない。see・interpretだけの追記は情報源の現実変更として数えない。状態scriptの改訂は、その状態を持つ存在の情報源版にも反映する。

interpretは主体→内容→対象が成立する期間を検査する。aboutのないcontentや、contentだけ有効でaboutが欠ける期間は確定できない。statusは対象のない性質も表せる。初期生成のseeには知覚内容を要求し、対象IDへの接続だけを知識とみなさない。

## 時間と参加

内部の世界内時間はT0=0からのミリ秒整数とする。行動要求は開始・到達目標を持ち、実際に解決した時点と未処理の継続を返す。次の起動は意図形成と作用解決を区別する。世界更新Agentが記述した私的な説明を、NPCの次の行動意図へ流用しない。

人間は試遊した村民とは別の新しい村民として参加する。これはユーザーが選択した方式である。共通の更新処理で新しい同一性・所属・初期知識を成立させ、試遊村民の知識を複製しない。試遊村民の存在・履歴・所有・観測・解釈は残す。操作権の登録と試遊起動の停止は構築セッション管理で接続する。

## 確認の限界

接続検査だけでは、自然言語の意味的な整合性や、明示入力の充足を証明できない。実モデル試験では重複した人物の生成、役割・所属の不足、観測本文の欠落が見つかった。履歴を改変せず、検出と修正、再確認を[実測記録](../evaluations/world-agent-2026-10-19.md)へ残す。Issue #25・#34全体の完了とは扱わない。
