# ADR-086 所在の本文は滞在先の呼び名にし、探索の道と場所の説明はGMが書き分ける

状態: 採用。2026年11月24日のユーザー判断を記録する。Issue #446 の対応。[ADR-063](ADR-063-routes-in-surroundings.md)の行き来の記述の記録の仕方を改める。

## 問題

位置と場所のつながりの記録に、書き方の問題が3つあった。どれも特定の世界や人物によらず起きる。

1. 所在の本文に、移動の申請の文（「畑から家へ歩いて帰る」）や乗り物の定型文（「乗り物で移動する」）が、そのまま入る。直接の滞在先は正しいのに、本文を読むと移動の途中に見え、次に移動するまでその文のまま残る。
2. 探索（`explore`）の行き来の記述に、申請の文（「〜への道を探す」）がそのまま入る。新しい場所には説明が付かない。
3. 探索で、接続元の説明にすでにある物や区画（湖畔の祠など）が、別の新しい場所として作られる。片方への作用がもう片方に読まれず、同じものが行き方によって別物として体験される。

## 決定

- **所在の本文は、直接の滞在先の呼び名にする。** 移動（`locate`）で直接の滞在先が決まれば、記録する所在の本文はその場所の呼び名とし、申請の `text` は使わない。直接の滞在先が決まらないときだけ `text` を使う。乗り物の移動・乗降、同行の移動、死亡による移動も同じ処理を通る。
- **探索の道の記述と場所の説明は、GMが書き分ける。** 探索の判定で、GMはダイス設定と同じ応答に `explored:{route, description, partOf}` を返す。`route` は接続元と新しい場所を結ぶ道の記述、`description` は新しい場所の様子である。成功すると、行き来の記述の本文を `route` にし、新しい場所に `description` を状態として付ける。
- **接続元の一部は、印を付けて作る。** 新しい場所が接続元の説明にすでにある物や区画なら、GMは `partOf` を true にする。このとき、新しい場所の説明から接続元へ、`text` が `part-of` の status/about を張る。接続元と行き来の記述は、ほかの探索と同じく作る。
- **一部の場所と接続元は、互いの様子を同じ材料として渡す。** GMやNPCへ渡す材料（`#facts`）で、場所を材料に含めるとき、`part-of` で結ばれた場所（一部と接続元）も材料に加える。一つの場所から加えるのは8件までとする。状態の読み出しや終了の候補（`#states`）は変えないので、別の場所の状態を終える対象にはしない。
- 過去の記録は変えない。既存のデータは必要に応じて管理修正で扱う。

## 受入条件と判定

特定の行動や結末は期待値にしない。

| 対象       | 期待結果                                                                               | 判定方法       |
| ---------- | -------------------------------------------------------------------------------------- | -------------- |
| 所在の本文 | 直接の滞在先を指定した移動では、申請の文によらず、所在の本文が滞在先の呼び名になる     | 結合試験       |
| 探索の指示 | 探索の判定の指示に `explored` の書き分けが入る                                         | 結合試験       |
| 道と説明   | 成功した探索では、行き来の記述がGMの `route` になり、新しい場所に `description` が付く | 結合試験       |
| 一部の場所 | `partOf` で作った場所は、接続元を材料にする次の判定に一緒に渡る                        | 結合試験       |
| 文書       | 解説と変更履歴に、所在の本文と探索の書き分けを書く                                     | 配布文書の照合 |

## 影響

- 所在の本文から、「岸辺の野営のそば」のような細かい位置は書けなくなる。細かい位置は状態や発言で表す。
- 探索の判定の出力が `explored` の分だけ増える。応答の `outcome.setting.explored` で読める。
- 一部の場所を持つ場所の判定では、材料が最大8件増える。
- プレイヤーCLIの解説が変わるため、CLIの版を 1.21.6 に上げる。
