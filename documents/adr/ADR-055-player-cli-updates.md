# ADR-055: プレイヤーCLIのメジャー互換性と更新

CLI 0.17.0から、プレイ端末のHTTP要求に `X-Gestaloka-CLI-Version` を付ける。接続申込みからSSEの再接続まで同じ版を送る。APIは公開中の配布物より古いメジャーを、処理前にHTTP 426と `PLAYER_CLI_UPDATE_REQUIRED` で拒否する。ヘッダーのない端末はメジャー0として扱う。0.xの配布中は従来の端末を使え、1.0.0の公開から更新が必要になる。プレイ端末APIを直接使うクライアントも対応する版をヘッダーで示す。

配布案内・最新版情報・アーカイブの取得には版制限やプレイ端末の認可を要求しない。Web画面のログインと管理者MCPはこの判定の対象外とする。

明示的なupdateは選択した接続先から最新版を取得し、同一origin、Node.jsの条件、サイズ、SHA-256、展開したパッケージ名・版・同梱スキル、新版の起動を照合する。新版は導入先の別ディレクトリへ配置し、検証後にrenameで公開する。共通の起動口は完成済みの最新リリースを選ぶため、並行更新や取得失敗で古い版に巻き戻らない。各Viewのプロファイルと要求記録は更新対象に含めない。

リリース担当者は `packages/player-cli/gameplay-changes.json` に版ごとのプレイ変更点を追加し、既出の版を残す。内部変更のみの版は空配列にする。履歴を同じ検証済みアーカイブに同梱し、更新成功時に「元の版より後、更新先以下」の変更だけを版順に返す。
