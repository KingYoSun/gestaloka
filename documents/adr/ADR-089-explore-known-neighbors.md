# ADR-089 探索は接続元からつながる既知の場所を判定に渡し、同じ場所なら作らず、つながる場所へは行き来も作る

状態: 採用。2026年11月24日のユーザー判断を記録する。[ADR-086](ADR-086-place-texts-from-place.md)の探索の判定に加える。Issue #446 の3点目のうち、ADR-086 で採らなかった「近くの既知の場所への解決」を扱う。

## 問題

ADR-086 の探索の判定でGMが見るのは、接続元と新しい場所の材料だけだった。接続元の説明にある区画は接続元の一部として作れるが、接続元から行き来でつながる既知の場所はGMに見えない。そのため、すでにある場所と同じ空間が別の場所として作られ、既知の場所の連なりにつながらないまま残った。

対象世界の記録（2026年11月24日）では、既存の場所の内部を探索した際、既知の経路からすでに到達できる空間が別の場所として作られた。新しい場所と既存の経路はつながらず、同じ空間が二重に記録された。この重なりは、行動の種類や世界の設定によらず起きる。

## 決定

- **接続元からつながる既知の場所を、判定に渡す。** 探索の判定の入力に `neighbors:[{id,label}]` を加え、その場所の材料（説明など）もGMへ渡す。接続元から行き来の記述でつながる場所を、8件までとする。
- **同じ場所なら作らない。** GMは、申請された場所が `neighbors` のどれかと同じなら、`explored.sameAs` にそのIDを返す。サーバーは、ダイスを振る前に `EXPLORE_SAME_PLACE` で断り、メッセージにその場所のIDを入れる。SPも通常枠も使わない。
- **つながる既知の場所へは、行き来も作る。** GMは、新しい場所から直接行き来できる `neighbors` の場所を、道の記述とともに `explored.connects:[{id,route}]` に返す。成功した確定で、新しい場所とその場所を結ぶ行き来の記述を加える。
- **渡した場所だけを受け付ける。** `sameAs` と `connects` は、`neighbors` に含まれるIDだけを残す。
- 文字列の照合はしない。同じ場所か、つながるかはGMが判断する。
- 行き来の記述を張る処理は、探索の行き来と共通の `linkRoute` にまとめる。

## 受入条件と判定

特定の行動や結末は期待値にしない。

| 対象       | 期待結果                                                                                     | 判定方法       |
| ---------- | -------------------------------------------------------------------------------------------- | -------------- |
| 判定の入力 | 接続元からつながる既知の場所が `neighbors` としてGMへ渡り、指示に `sameAs` が入る            | 結合試験       |
| 同じ場所   | GMが `sameAs` を返すと `EXPLORE_SAME_PLACE` とそのIDが返り、場所は作られず、通常枠も使わない | 結合試験       |
| つながり   | GMが `connects` を返すと、新しい場所とその既知の場所の行き来ができ、接続元との行き来も残る   | 結合試験       |
| 文書       | 探索の解説、エラー表、変更履歴に、同じ場所とつながりを書く                                   | 配布文書の照合 |

## 影響

- 探索の判定の入力に、既知の隣の場所が最大8件と、その材料が加わる。出力の `explored` に `sameAs` と `connects` が加わることがある。
- 新しいエラー `EXPLORE_SAME_PLACE` が加わる。
- 過去に重なって作られた場所は変えない。必要に応じて管理修正で扱う。
- プレイヤーCLIの解説が変わるため、CLIの版を 1.21.10 に上げる。
