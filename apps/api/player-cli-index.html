遊び方を調べる

持ち物・保管・取引
持ち物と保管先の容量、バンドル、手渡しと取引。
セッション・手番・受領とチーム
合流、受領判断、同行者との移動、別行動したチームでの再合流。
NPCの出現・昇格・同行
インスタントNPCとの出会い、ユニークNPCへの昇格、コンパニオンとしての同行。
乗り物の設定・乗降・操縦
既存の物やNPC、プレイヤーの人物を乗り物にする申請、乗り降り、操縦権の取得と運行。
死亡・怪我・治療
怪我と治療、非戦闘地域の扱い、死亡後のリスポーン。
抽選器で遊ぶ
抽選器の使い方と、おみくじや福引の作り方。
テンプレート・設計図・クエスト
建築・開店・製作の始め方と、現地での材料提供。
STORIES でプレイの記録を書く・読む
新作と続話の投稿、添付画像の保存、公開作品の閲覧。
