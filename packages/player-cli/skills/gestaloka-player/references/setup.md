# Muse・Grok Botが遊ぶ準備をする

このページはAI向けの手順。持ち主が渡した村で、本人が許可した村民として遊ぶ準備に使う。人間にファイルの取得、コマンド実行、実行環境の設定を頼まず、自分の実行ツールで進める。

## 人間への伝え方

準備中の発言、進捗の短い案内やタスク名、許可を頼むとき、失敗や完了を知らせるときは、ふだんの言葉を使う。CLI、API、Node.js、ターミナル、プロファイル、トークン、認可、デバイス、ハッシュなどの専門用語や、内部のID・エラー・コマンドを人間への発言へ持ち出さない。これらは自分の作業内で扱う。秘密値を会話へ貼らない。

- 始めるとき: 「この村で遊ぶ準備をするね。あなたの操作が必要になったら案内するよ。」
- 許可が必要なとき: 「この画面を開いて、確認のことば『〈userCode〉』が同じか確かめてね。私が遊ぶ人物を選び、『この村民のプレイを許可する』を押してください。終わったら『できた』と教えてね。〈verificationUrl〉」
- すでに遊べるとき: 「前と同じ村民で、続きから遊べるようになったよ。」
- 準備が終わったとき: 「準備ができたよ。私はこの村の〈名前〉として遊ぶね。」
- 自分で先へ進めないとき: 「今は準備を進められなかったよ。まだ遊び始めていないので、少し後でもう一度試してみよう。」

失敗の説明は、実際に確認した状況、今できること、必要なら人間にしてほしい操作を短く伝える。確認できていない原因を断定しない。実行環境が人間の確認を求めた場合は、その仕組みに従い、画面上の操作をふだんの言葉で案内する。

## 接続先と配布物

この案内を取得したURLのoriginを接続先とする。`?world=<UUID>`があれば、その村を使う。持ち主が別に渡した村のURLまたはIDも使える。村が指定されていないときだけ「遊びたい村のページを教えてください」と尋ねる。

接続先の`GET /api/player-cli/latest`を取得する。返却の`version`がこの接続先で公開中の最新版、`downloadUrl`が配布物、`sha256`が照合する値、`node`が対応する実行環境の版。相対URLは、同じ接続先を基準に解決する。ログインは不要。

実際の実行ツールのOSとNode.jsの版を調べる。Grok BotのWindowsアプリでも、実行ツールはLinuxの場合がある。対応版が既にあるならそれを使う。必要ならNode.js公式の`https://nodejs.org/dist/index.json`から`node`の条件を満たす版を選び、OS・CPUに合う配布物と同版の`SHASUMS256.txt`を取得して照合し、自分用の永続的な場所へ展開する。環境のプロキシと証明書を維持し、必要に応じて対応Nodeの`--use-env-proxy`を使う。TLS検証は無効にしない。

`downloadUrl`のファイルを取得し、実際のSHA-256が返却値に一致することを確かめてから、専用の場所へ展開する。展開後の`package/package.json`の版と`version`が一致すること、`node <絶対パス>/dist/main.js help`の正常終了を確かめる。同梱の`skills/gestaloka-player/SKILL.md`と`references/runtimes.md`を読み、以後は実際の実行環境に合う起動形を使う。コマンドや照合値を人間に実行・判断させない。

## 許可と参加

既存の人物ごとの保存先を確認し、同じ村の準備済みの記録があれば引き継ぐ。許可と要求の記録は、配布物の展開先と別に保存する。値を本文へ出力しない。

同じ保存先の`status`で状態を確認する。初回だけ`connect --server <接続先> --world <村> --profile <保存先>`を一度実行し、返った`verificationUrl`と`userCode`を上の例の言葉で持ち主へ渡す。自分で許可の画面を押したり、持ち主のログイン情報を求めたりしない。持ち主が終わったら`status`で許可を確認する。

`authorized`なら`join`を一度実行し、実行ツール内で本人の生成完了を待つ。既存人物を選んだときは`join`を省く。処理中は実行ツール内で待ち、新しい要求を重ねない。通信応答が失われたら保存済みの同じ要求IDを`recover`で照合する。許可を取り消されていたときは、本人による新しい許可が必要と伝える。

本人の`knowledge`と現在の場面・結果を読み、続きから遊べることを確かめる。準備の確認だけのために、新しい場面や一手を作らない。持ち主へは本人の名前と準備の完了を短く伝え、その後のプレイは同梱スキルに従う。
